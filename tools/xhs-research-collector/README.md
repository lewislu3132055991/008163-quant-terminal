# 008163 小红书研究采集器

这是一个本地 Chrome 扩展，只在 `xiaohongshu.com` 上运行。它复用用户已经登录的页面，不读取密码、Cookie、浏览历史，也不会点赞、收藏、评论或发布内容。

## 安装

1. 解压 `xhs-research-collector.zip`。
2. 在电脑 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
3. 选择“加载已解压的扩展程序”，指向解压后的文件夹。

## 研究流程

1. 在小红书搜索一个主题，点击扩展中的“扫描当前搜索页”。
2. 点击“开始本批”，每次最多读取 6 篇，篇间随机等待 12 至 20 秒。
3. 点击“导出研究 JSON”。原始正文只保存在该本地文件中，不发布到 GitHub。

v0.2 已兼容新版搜索结果的 `/search_result/笔记ID` 链接。以长图为正文、网页文字很少的帖子会标记为 `needsOcr` 并保留，不再反复判定为读取失败；这类帖子仍需人工核对图片内容后才能进入规则审计。

采集器遇到登录、验证码或访问风控会停止，不会尝试规避平台控制。社区帖子只用于发现量化假设，任何规则必须再用 008163 的复权历史数据验证。
